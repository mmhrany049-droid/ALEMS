# ۱. چشم‌انداز و محدوده — ALEMS نسخه ۲

## ۱.۱ چشم‌انداز

ALEMS 2 سیستم عامل شخصی دانش‌آموز کنکوری است:
ثبت واقعیت مطالعه، سنجش درست، مرور هوشمند، برنامه‌ریزی واقع‌بینانه، و بازخورد قابل فهم — با ظاهری مدرن و لذت‌بخش.

## ۱.۲ مسئله

نسخه ۱ پایه را گذاشت اما:
- Import فهرست بدون سوال سخت بود
- موتور تست/تحلیل به عمق SS459 نرسید
- ظاهر ساده بود
- ظرفیت واقعی، taught، و حلقه بازخورد ناقص بود

نسخه ۲ این شکاف‌ها را می‌بندد.

## ۱.۳ اصول محصول

1. واقعیت را ثبت کن، بعد قضاوت کن  
2. Coverage ≠ Accuracy ≠ Volume  
3. taught ≠ learned  
4. free time ≠ capacity  
5. کاربر صاحب تصمیم نهایی است  
6. زیبایی و سرعت حس کیفیت می‌دهد  
7. داده متعلق به کاربر است  

## ۱.۴ داخل محدوده نسخه ۲ (In Scope)

### هسته
- ماژولار، Offline-first، backup/restore، export، settings، audit سبک

### کاربر
- پروفایل تحصیلی، onboarding، daily check-in، state ساده، taught topics

### کتاب و تست
- TOC-only import، import کامل، نوع بلوک (topic/mixed/exam/konkur)
- Test Engine: range، زوج/فرد، timed/untimed، past import
- NOT_ENTERED / UNANSWERED / ANSWERED
- دفترچه خطا، تیک‌ها، time tracking

### مرور و یادگیری
- صف مرور + چرخه ۱-۳-۷-۱۴ + مرور خوشه‌ای/تصادفی
- Learning State چندبعدی سبک
- Weakness detector عملی

### برنامه و ظرفیت
- تقویم شمسی، Today Hub، برنامه روز/هفته
- ظرفیت واقعی، school/class constraints، override
- Manual override کامل
- Priority و Recommendation سبک
- Recovery عقب‌افتادگی بدون dump روی فردا

### آزمون و هدف
- Exam Center (آزمایشی + امتحان)
- درصد کنکوری
- اهداف بلند/ماهانه/هفتگی + هدف سه‌ماهه ساده
- پیگیری فاصله تا هدف کنکور (نمایشی)

### تحلیل
- متریک‌های جدا، نمودار، گزارش، PDF/Excel/JSON
- Explainability پایه برای پیشنهادها

### انگیزش
- امتیاز، streak، نشان
- عادت‌advice بعد از ۳۰ روز داده
- تشخیص اهمال‌کاری ساده + نقطه ورود کوچک

### UI
- طراحی بصری جدید
- انیمیشن‌های معنادار (Framer Motion)
- تاریک/روشن، Focus Mode، Empty State قوی

### همکاری پایه
- اشتراک گزارش کنترل‌شده با مشاور/والد (سطح ساده)

## ۱.۵ خارج از محدوده نسخه ۲ (Out of Scope)

- شبکه عصبی / مدل زبانی داخل محصول
- Spaced Repetition کامل Ankiگونه
- Social، لیگ، رقابت عمومی
- همگام‌سازی ابری چنددستگاهی پیچیده
- اپ Native
- پیش‌بینی آماری سنگین رتبه کنکور
- پیام‌رسان داخلی کامل

## ۱.۶ معیار موفقیت نسخه ۲

- کتاب فقط‌فهرست در کمتر از ۳۰ ثانیه import می‌شود
- ثبت ۱۰ تست متوالی روان و سریع است
- Today Hub در یک نگاه وضعیت روز را می‌گوید
- Coverage/Accuracy/Volume در گزارش هفتگی جدا هستند
- برنامه هفتگی با ظرفیت مدرسه تولید می‌شود و دستی کاملاً قابل ویرایش است
- ظاهر از نظر کاربر «نسخه جدید» حس می‌شود نه پوسته‌ای روی V1
- Backup/Restore و Export بدون از دست رفتن داده
