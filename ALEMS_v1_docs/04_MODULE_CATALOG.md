# ۴. کاتالوگ ماژول‌ها (Module Catalog) — نسخه ۱

این سند مرجع اصلی برای پیاده‌سازی ماژول‌ها است.
ماژول‌هایی که در نسخه ۱ **اجباری** هستند با `[V1]` مشخص شده‌اند.
ماژول‌های پیشنهادی برای نسخه‌های بعدی با `[V2+]` علامت خورده‌اند.

---

## لایه ۱ — هسته سیستم (Foundation)

### 1. Core System Module `[V1]`
**هدف:** هماهنگی کلی برنامه، مدیریت رویدادها و تنظیمات مرکزی.

**مسئولیت‌ها:**
- بارگذاری تنظیمات
- Event Bus داخلی
- مدیریت چرخه عمر برنامه
- ثبت لاگ خطاهای داخلی

**وابستگی:** ندارد (پایه همه چیز)

---

### 2. Database Management Module `[V1]`
**هدف:** ارتباط با پایگاه داده و مدیریت ساختار.

**مسئولیت‌ها:**
- اتصال به SQLite / PostgreSQL
- ایجاد و به‌روزرسانی جداول از طریق Alembic
- مدیریت نسخه schema

---

### 3. File Management Module `[V1]`
**هدف:** مدیریت فایل‌ها و پوشه‌های استاندارد پروژه.

**مسئولیت‌ها:**
- مسیرهای استاندارد (data، backups، exports، imports)
- خواندن و نوشتن JSON
- مدیریت فایل‌های خروجی

---

### 4. Backup & Restore Module `[V1]`
**هدف:** حفظ و انتقال داده‌ها.

**مسئولیت‌ها:**
- Backup دستی
- Backup خودکار (زمان‌بندی‌شده)
- Restore کامل
- پشتیبانی از رمزنگاری اختیاری

---

### 5. Version Management Module `[V1]`
**هدف:** آمادگی برای توسعه چندساله.

**مسئولیت‌ها:**
- ثبت نسخه برنامه و schema
- اجرای migrationها
- Changelog ساده

---

## لایه ۲ — کاربران و هویت

### 6. User Identity Module `[V1]`
**هدف:** مدیریت کاربران.

**مسئولیت‌ها:**
- ساخت کاربر
- احراز هویت (نام کاربری + رمز)
- هش امن رمز عبور

---

### 7. Session Management Module `[V1]`
**هدف:** مدیریت نشست پس از ورود.

**مسئولیت‌ها:**
- ایجاد و اعتبارسنجی Session/JWT
- ورود سریع
- خروج و تعویض کاربر

---

### 8. Permission Module `[V1]`
**هدف:** کنترل سطح دسترسی.

**نقش‌های نسخه ۱:**
- `student` (پیش‌فرض)
- `admin` (تنظیمات و backup)

نقش‌های مشاور و والد در V2 اضافه می‌شوند.

---

## لایه ۳ — اطلاعات دانش‌آموز

### 9. Student Profile Module `[V1]`
**اطلاعات:**
- نام
- پایه (دهم / یازدهم / دوازدهم / فارغ‌التحصیل)
- رشته (ریاضی / تجربی / انسانی)
- سال تحصیلی
- هدف کنکور (رشته و دانشگاه هدف — اختیاری)

---

### 10. Student State Module `[V1]`
**ثبت روزانه:**
- سطح انرژی (۱ تا ۵)
- وضعیت روحی (اختیاری)
- شرایط مطالعه (خسته، متمرکز، پراکنده و...)

---

### 11. Psychology & Behavior Module `[V2+]`
پرسشنامه اولیه و تحلیل رفتار — در نسخه ۱ پیاده‌سازی نمی‌شود.

---

## لایه ۴ — دانش آموزشی

### 12. Academic Knowledge Base Module `[V1]`
**ساختار درختی:**
```
رشته → پایه → درس → فصل → مبحث → زیرمبحث
```

دروس پیش‌فرض نسخه ۱: ریاضی، حسابان، آمار و احتمال، هندسه، فیزیک، شیمی، زیست (بر اساس رشته).

---

### 13. Resource Management Module `[V1]`
**انواع منبع:**
- کتاب تست
- کتاب درسی
- جزوه
- کلاس
- ویدئو

---

### 14. Book Import Module `[V1]`
**وظیفه:** وارد کردن کتاب تست از فایل JSON استاندارد.

**محتوای JSON:**
- اطلاعات کتاب
- فهرست فصل‌ها و مباحث
- سوالات + پاسخنامه

---

### 15. Question Bank Module `[V1]`
ذخیره سوالات با:
- شماره سوال
- متن یا ارجاع
- پاسخ صحیح
- مبحث مرتبط
- منبع

---

### 16. Question Classification Module `[V1]`
- سطح سختی (آسان / متوسط / سخت)
- نوع سوال
- اهمیت
- تگ‌های آزاد

---

## لایه ۵ — فعالیت آموزشی

### 17. Learning Activity Module `[V1]`
ثبت انواع فعالیت:
- مطالعه
- تست‌زنی
- مرور
- کلاس
- مدرسه

---

### 18. Test Record Module `[V1]`
ثبت نتیجه هر سوال:
- درست
- غلط
- نزده
- تاریخ و زمان حل (اختیاری)
- مدت زمان حل (اختیاری)

---

### 19. Question Marking Module `[V1]`
تیک‌های قابل انتخاب برای هر سوال:
- مهم
- مرور
- سخت
- اشتباه
- نکته‌دار

یک سوال می‌تواند چندین تیک همزمان داشته باشد.

---

### 20. Error Notebook Module `[V1]`
برای هر غلط ثبت می‌شود:
- نوع اشتباه: بلد نبودن / فراموشی / بی‌دقتی / کمبود زمان
- توضیح اختیاری

---

### 21. Review Management Module `[V1]`
**ورودی:** غلط‌ها + نزده‌ها + سوالات با تیک مرور/مهم/سخت  
**خروجی:** صف مرور روزانه  
**عمل:** علامت «مرور شد»

---

### 23. Calendar Module `[V1]`

- هفته ایرانی (شنبه تا جمعه)
- ثبت تعطیلات رسمی (ساده)

---

### 24. Time Management Module `[V1]`

- مدرسه

- زمان آزاد

---

### 25. Planning Module `[V1]`
تولید و ویرایش:
- برنامه روزانه
- برنامه هفتگی
- (برنامه ماهانه ساده)

---

## لایه ۷ — آزمون و ارزیابی

### 26. Exam Management Module `[V1]`
**انواع:**
- آزمون آزمایشی (چند درس + چند مبحث)
- امتحان (یک درس + چند مبحث)

---

### 27. Scoring Module `[V1]`
محاسبه:
- درصد کنکوری: `(درست - ۰.۳۳ × غلط) / کل × ۱۰۰`
- درصد بدون غلط: `درست / کل × ۱۰۰`

---

### 28. Difficulty Performance Module `[V1]`
تحلیل درصد به تفکیک:
- آسان
- متوسط
- سخت

---

### 29. Analytics Module `[V1]`
تحلیل عملکرد بر اساس:
- درس
- فصل
- مبحث
- زمان
- روند رشد ساده

---

### 30. Visualization Module `[V1]`
نمودارهای پایه:
- خطی (روند)
- میله‌ای
- دایره‌ای
- راداری (اختیاری)
- تقویم حرارتی عملکرد (ساده)
