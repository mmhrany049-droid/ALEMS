### محدوده نسخه ۱ (MVP + Core)

نسخه ۱ روی این محورها تمرکز دارد:

1. هسته سیستم و مدیریت کاربر
2. پروفایل و وضعیت دانش‌آموز
3. ساختار دانش آموزشی + بانک سوال
4. ثبت فعالیت مطالعه و تست
5. دفترچه خطا و سیستم مرور
6. برنامه‌ریزی ساده (روزانه/هفتگی)
7. آزمون و نمره‌دهی
8. تحلیل و نمودارهای پایه
9. گزارش و خروجی

ماژول‌های همکاری پیشرفته، هوش مصنوعی محلی، همگام‌سازی چنددستگاهی و داشبورد والد/مشاور در نسخه‌های بعدی قرار می‌گیرند.
